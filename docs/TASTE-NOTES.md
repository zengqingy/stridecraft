# Stridecraft 视觉整理记录

类型：实体助行器品牌。沿用现有三页结构与五段首页顺序；主动作是查看产品或提交咨询。字体保留 Noto Serif SC / Noto Sans SC，颜色使用用户给定令牌。真实资料只有演示线稿与概念模型，未补造产品承诺。

## 调整前的六处问题

- 首页只有口号与居中的按钮，既没有产品名，也没有产品主体；大面积空白没有锚点。
- 大宋体、极小的全大写英文眉题、正文之间缺少稳定比例；品牌名与产品名没有明确分工。
- 列表混排 3D、SVG、长画布说明、价格与折叠图标，用户需要重复筛选同样的信息。
- 透明 WebGL 后的 SVG 造成双重轮廓，像调试过程中的占位层。
- 详情页将配色、视角按钮和重复免责声明堆在图片下方，咨询动作的优先级偏低。
- 三轮 CSS 累积了旧绿、旧米色、不同圆角与间距。动作时长本身合理，缺少的是一致的悬停反馈与静止状态。

## 概念参照与应用

### Apple

1. 一段一个主题：首页依次承担认识产品、观察角度、选型、理念和咨询。
2. 产品先出现：第一屏显示首款产品名与完整 SVG；特色区才解释三个观察角度。
3. 留白服务主体：去掉卡片里的重复解释，放大产品与名称，不用徽章或装饰填空。

### Stripe

1. 明确层级：名称、价格、资料和咨询按钮各有固定位置，规格用对齐的行呈现。
2. 信任来自可核实的内容：保留演示价格与待确认规格，不添加认证或评价。
3. 排版比装饰重要：两套字体固定分工，只保留已有玻璃边缘的极浅渐变，不做渐变文字。

### Linear

1. 用信息密度和纪律建立克制感：保留浅色背景，用纸色区分理念带，不引入新的深色主题。
2. 每个状态都明确：卡片轻抬 2px，按钮轻移 1px；焦点即时显示，配色和重置可用键盘。
3. 安静的速度：保持原 .8s / 1.1s / .6s 时序与无回弹 easing；列表改用 SVG，3D 留给解释产品的区域。

## 本轮范围

- 首屏产品名取首款产品 name；原 headline 作为辅助品牌句，后台仍可编辑。
- store.js 只更新默认颜色名、只读展示色板与同步的内嵌 SVG；localStorage 键、数据形状、保存/导入/导出/渲染函数未改变。已有浏览器记录不迁移。
- 列表与首页精选使用现有 SVG；特色区和详情页保留懒加载 3D。SVG poster 在模型成功呈现后隐藏，失败时立即恢复。
- 概念照片复用已存在的固定 seed URL，仅作理念氛围，绝不当作真实产品照片。
- 产品展示色：米白、豆绿、暖驼；这是材料选项，界面只用苔绿作为强调色。

## 技能规则与本任务边界

已完整阅读安装的 design-taste-frontend/SKILL.md。用户给定的颜色、字体、SVG、演示标识、滚动时序和“taste intervention, not a rebuild”优先，因此没有随机重选布局/配色、复制技能模板、删除演示说明或替换数据层。

技能 gate/check/shoot 的脚本会启动 127.0.0.1 HTTP 服务。遵守本项目禁止本地服务器的要求，本轮未运行技能的服务式 gate；没有 GATE: PASS 声明。改用 Playwright 响应拦截、截图、axe 与既有功能检查。附属技能包、第三方库和历史审计报告原样保存，颜色扫描不改动这些参考资料。

## 仍弱的地方

10 款默认 SVG 共享同一几何形态，概念模型材质也较粗糙；它们尚不能建立真实产品差异。需要真实产品摄影、经过优化的 GLB，以及确认过的规格、价格、交付和服务资料。Google Fonts 和 Lottie CDN 在当前云浏览器中受网络/信任限制，回退已验证，线上真实网络仍需复查。
